
1. connet the robot arm to ubuntu with cable

2. run remote_ctrl_arm_gripper_udp.py on ubuntu

3. quest & ubuntu should connet to the same WiFi

4. get WiFi IP address of ubuntu

5. run DataEngine in quest, input WiFi IP

6. press x+a call out coordinate, left-hand trigger adjust origin, right-hand trigger adjust z-axis, x+a close coordinate

7. press 'controller' on gui panel to start controller

8. keep right-hand middle trigger pressing to remote control robot arm

9. press 'controller' on gui panel again to end controller
